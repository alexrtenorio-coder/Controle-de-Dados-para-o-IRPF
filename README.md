# Controle de Dados para Organização do IRPF

## Sobre o projeto

Este projeto tem como objetivo desenvolver uma planilha de controle de dados no Microsoft Excel para facilitar a organização das informações necessárias à preparação da Declaração do Imposto de Renda da Pessoa Física (IRPF).

A ferramenta utiliza validação de dados, fórmulas, filtros e recursos de navegação para tornar o processo de organização mais simples, estruturado e eficiente.

## Objetivos

- Centralizar informações financeiras e patrimoniais.
- Organizar rendimentos e despesas por categoria.
- Registrar bens e direitos.
- Acompanhar documentos e pendências.
- Reduzir erros de preenchimento por meio de validações.
- Apresentar indicadores básicos para conferência.

## Funcionalidades planejadas

- Cadastro e organização de rendimentos.
- Registro de despesas e referências de comprovantes.
- Controle de bens e direitos.
- Listas suspensas para padronização de categorias.
- Cálculo automático de totais.
- Filtros para consulta de informações.
- Checklist de documentos pendentes.
- Painel de resumo financeiro.

## Tecnologias e recursos

- Microsoft Excel
- Fórmulas e funções de planilha
- Validação de dados
- Formatação condicional
- Tabelas e filtros
- Gráficos e indicadores

## Estrutura das informações

A planilha será organizada em abas:

1. **Início:** instruções e resumo dos dados.
2. **Rendimentos:** fontes pagadoras, categorias e valores.
3. **Despesas:** despesas registradas e situação da conferência.
4. **Bens e Direitos:** inventário de bens e valores.
5. **Pendências:** documentos e informações a verificar.

## Privacidade e segurança

O repositório deve utilizar exclusivamente dados fictícios para demonstração. CPF, endereço, dados bancários, informes de rendimentos e comprovantes pessoais não devem ser publicados.

## Limitações

Esta ferramenta tem finalidade organizacional e educacional. Não substitui o programa oficial da Receita Federal, não determina automaticamente a dedutibilidade de despesas e não garante a correção de uma declaração fiscal.

As regras devem ser conferidas conforme o exercício fiscal correspondente.
